
# PHP Básico

Atividades práticas de Programação Web I (Técnico em Informática).

**Aluno:** Talita

## Projetos

- 01-hello-world: primeira página em PHP
- 02-data-hora: data e hora do servidor
- 03-imc: calculadora de IMC
- 04-produtos: lista de produtos com array associativo

## Como executar

1. Instalar o Laragon e iniciar os serviços.
2. Colocar esta pasta em `C:\laragon\www\talita\php-basico`.
3. Abrir `http://localhost/talita/php-basico/` no navegador.

## O que aprendi

- Criar páginas usando PHP.
- Trabalhar com variáveis e condições.
- Utilizar arrays e estruturas de repetição.
- Criar tabelas HTML e funções em PHP.

## Soluções alternativas que testei

Utilizei diferentes estruturas do PHP, como `if`, `foreach`, operador ternário e funções para organizar e apresentar os dados.
